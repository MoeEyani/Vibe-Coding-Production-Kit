# Vibe Coding Production Kit v0.8.0

Vibe Coding Production Kit turns informal AI-assisted coding into a repository-native engineering workflow: source-of-truth specs, bounded tasks, readiness gates, phase-specific context, verification evidence, independent review, and production-minded delivery.

## Highlights

- **Bootstrap safely** with a zero-runtime-dependency Node.js CLI.
- **Adapt to TypeScript, Python, and Go** using evidence-based stack detection.
- **Create bounded task packs** with `vcp task`.
- **Separate planning readiness from implementation readiness** with `vcp ready`.
- **Build minimal phase-specific AI context** with `vcp context`.
- **Turn “tests passed” into durable evidence** with safe-by-default `vcp verify`.
- **Audit repository readiness** with read-only `vcp doctor`.
- **Study a worked security-sensitive multi-tenant example** under `examples/reference-saas-invite/`.

## Try it without installing globally

```bash
npx --yes github:MoeEyani/Vibe-Coding-Production-Kit init . --agent all --stack auto --yes
```

Then follow [`docs/QUICKSTART.md`](../QUICKSTART.md).

## Verification model

`vcp verify <task>` previews repository-controlled commands and executes nothing by default. Execution requires explicit `--run`, requires the task to pass the implementation-readiness gate, stops after the first failure, and can write JSON evidence without persisting raw stdout/stderr.

## Compatibility

- Node.js 22+
- Zero runtime dependencies
- Agent-agnostic workflow
- Thin adapters for Claude Code and GitHub Copilot
- Repository-native `AGENTS.md` flow for Codex, Cursor, and compatible agents
